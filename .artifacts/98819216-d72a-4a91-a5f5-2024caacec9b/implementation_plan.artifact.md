# Fix tough-cookie ESM default export issue

The project is experiencing a `SyntaxError` on Vercel because `tough-cookie` (version 6.x) is an ESM-only (or dual-module) package that does not provide a default export, but the server-side bundle (generated by Vite/Nitro) is attempting to use it as a default import. This typically happens when `jsdom` (which depends on `tough-cookie`) is bundled via `noExternal`.

## Proposed Changes

### [Component Name]

#### [NEW] [tough-cookie-shim.ts](file:///D:/skill-shine-gateway-main-main-main/src/tough-cookie-shim.ts)
Create a shim file to provide a default export for `tough-cookie`, following the existing pattern for other dependencies like `parse5` and `@asamuzakjp/css-color`.

#### [MODIFY] [vite.config.ts](file:///D:/skill-shine-gateway-main-main-main/vite.config.ts)
1. Add an alias for `tough-cookie` pointing to the new shim.
2. Add `tough-cookie` to the `noExternal` list to ensure it's bundled and the alias is applied correctly during the SSR build.
