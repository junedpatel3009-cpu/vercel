# Repository structure

| Path | Responsibility / add code here |
| --- | --- |
| `src/routes/` | TanStack file routes; add page routes and API-file routes |
| `src/client/`, `src/professional/`, `src/admin/` | Role-oriented UI/features |
| `src/backend/` | HTTP API router, auth, email, database helpers and tests |
| `src/lib/` | Server repositories, sessions, Prisma, validation, CMS and utilities |
| `src/components/` | Reusable React/layout/UI components |
| `src/store/` | Redux store and auth/profile slices |
| `src/generated/prisma/` | Generated Prisma output; never edit manually |
| `prisma/` | Prisma schema and migration history |
| `server/` | Node production wrapper and Socket.IO runtime |
| `api/ssr.ts` | Vercel SSR function entry point |
| `scripts/` | Admin, database-inspection/migration and CMS sync scripts |
| `flutter_app/` | Flutter client; `lib/` holds app, screens, local database and HTTP client |
| `storage/` | Runtime-generated private reports/uploads; do not commit secrets or production data |

Ignore `node_modules`, `dist`, generated route/client artifacts, local DB WAL/SHM files, archives, and report output when navigating. `src/routeTree.gen.ts` is generated by TanStack tooling; do not hand-edit it.
