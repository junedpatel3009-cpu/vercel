# Contributing

1. Set up the project using [Setup](SETUP.md).
2. Keep changes scoped; do not edit generated files or commit `.env`, runtime storage or local databases.
3. Add/update validation, authorization checks, tests and documentation for behavior changes.
4. Run `npm run lint`, `npm test`, and `npm run build` before requesting review.

Branch naming, commit format, pull-request template, required reviewer count, release ownership and security-reporting contact are not defined in this repository—**Needs confirmation**. Report a potential vulnerability privately to the repository owner rather than filing an issue with exploit details.
